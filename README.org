#+title: gptel-agent

=gptel-agent= gives your Emacs chats tools to work with files, search the web,
run shell commands, and delegate tasks. This independently developed fork
builds on [[https://github.com/karthink/gptel-agent][karthink's gptel-agent]] for [[https://github.com/karthink/gptel][gptel]].

* What this fork adds

- Enable or disable sub-agents and skills per chat with
  =M-x gptel-agent-toggle-agent= and =M-x gptel-agent-toggle-skill=.
- Give a new sub-agent or discussion extra tools for its task.
- Set tool policies that control allowed calls by name and argument.
- Let the agent start and manage separate chat threads called discussions.
- Run Bash in the background and manage jobs with the =Process= tool.

[[https://github.com/SamuelVanie/gptel-ui][gptel-ui]] is an optional reading view with foldable tool output and shortcuts
for jumping between turns and pending approvals.

* Quick start

With Emacs 30+ and gptel 0.9.9.6 or newer, add this to your init file.

#+begin_src emacs-lisp
(use-package gptel-agent
  :vc (:url "https://github.com/SamuelVanie/gptel-agent" :rev :newest)
  :config (gptel-agent-update))
#+end_src

After configuring your gptel backend and model, run =M-x gptel-agent= and send
your first prompt with =gptel-send=.
